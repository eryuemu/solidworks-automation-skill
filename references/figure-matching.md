# 按图装配：从等轴测图反推位姿与视觉核对

适用场景：

- 指导书/老师给的是一张**装配等轴测图**（线图或截图），要求把零件装得与图一致；
- 用户说“看着不一样 / 像装反了”，需要判断是**视角问题**还是**零件位姿问题**；
- 装配体“配合全过、干涉 0”，但外形与图对不上。

核心原则：

1. **先量后看**：等轴测/二等轴测的轴向投影角是固定值，先量角度确定投影基，再谈几何。
2. **不拿 2D 偏移推 3D**：屏幕上“杆相对孔偏了”可能只是拍照透视/视差。
3. **判据用精确投影叠加或同视角渲染**，不用局部放大图硬看。
4. **±90°、镜像这类离散歧义，先给 A/B 候选让用户确认**，再批量改模型与交付物。
5. **“干涉 0 + 配合齐全”不等于装法对**；最终判据是“与图的同视角对照 + 位姿回读”。

---

## 1. 建立投影基（量角，不靠感觉）

- 用 PIL + numpy 对图做 Hough（0.5° 步长，限制在感兴趣区域），统计主要线角。
  真实案例中三轴投影是两组对称角 + 一条竖直：**±26.565° = atan(0.5)**（SW 的 Dimetric 角度）。
- 把角度对应到世界轴：拿两根以上已知轴线（如杆件轮廓）交叉确认，别只凭一根线。
- 若图就是 SW 的 Dimetric 截图，相机基（屏幕右 r / 上 u / 朝向观察者 w）为：

```text
r = ( 0.7071, 0,      0.7071)
u = ( 0.3536, 0.8660, -0.3536)
w = (-0.6124, 0.5,     0.6124)   # r × u
# 投影：u_px ∝ p·r，v_px ∝ p·u；X 右上、Y 上、Z 右下均 26.565°
```

- 反例：SW 自带 `ShowNamedView2("", 9)`（Dimetric）从 **+X 侧**看，导出的是背面；
  需要自定义 `IModelView.Orientation3`（见 `docs/solidworks-com-pitfalls.md` 第 44 条）。

## 2. 从图反推每块板的局部坐标系

先认清零件特征（以“弯板”为例）：底板（大面）、两条侧折边（导轨，12 高）、前折边（凸缘，带 Ø15 孔 + 45° 倒角）、底板孔（板心）、折边孔。

判据顺序（**至少两条独立特征交叉确认**）：

1. 找**凸缘**（带 45° 倒角的竖板）→ 它所在的板边是底板的一条 90 边；
2. 找**导轨**（两条 12 高的窄条）→ 在另两条 60 边上，且朝底板法向的**反侧**；
3. 定**底板法向**（朝上/朝下）→ 决定底面哪一面可见、凸缘朝哪；
4. 用**孔位关系**收尾：底板孔在板心，折边孔距板心 44 mm（34 + 28 的斜向）。

常见误判：只用“边上有一根白条”判导轨方向、把折边/凸缘看反、把板边的厚度线当成导轨。
局部放大图里一条边可能同时有板边、折边、倒角、孔多条线——**先在全图定轮廓，再放大**。

## 3. 枚举候选位姿（把“感觉”变成有限选项）

- 装配约束通常写作“Ø15 圆柱/孔同轴心 + 圆柱端面与板面重合”；**绕孔轴的角向**是剩下的自由度。
- 同轴心 + 重合只约束 5 个自由度；链式装配有 5 个这样的角向自由度。
  `lock_rotation=True` 只是把求解器锁在你给的初始位姿上，**不代表初始位姿正确**。
- 对每块板：绕孔轴每 90° 一个轴对齐候选。底板孔在板心时 **4 个候选都“装得上”**，
  必须靠图上的凸缘方位/导轨方向筛。

## 4. 精确投影叠加（推荐做法）

- 已有模型与相机基时，把模型的已知边线投影到图纸像素：
  - **比例**：用图上已知直径/长度标定（如 Ø32 杆的轮廓宽 = 32 mm）；
  - **平移**：用杆轴（竖直圆柱的两条轮廓线中点）或孔心对齐。
- 把投影线画成红色叠在原图上，差异一眼可见。
- 若模型还没建：直接在 SolidWorks 里用同一个 `Orientation3` 出同视角渲染，与图并排/半透明叠加。
- **注意**：教材插图常是手绘/近似投影（长度比例不严格），叠加对不齐时**不要追像素**，
  改用定性判据（凸缘在哪一侧、导轨朝哪、孔相对板边的位置关系）。

## 5. 几种高频误判

| 误判 | 真相 | 规避 |
|---|---|---|
| 手机拍屏/拍纸后，杆和孔错位 | 透视/视差假象（杆比板低几十 mm，翻拍就会偏） | 用保存的 PNG/扫描件做几何判定，不用翻拍图 |
| “凸缘在板的右侧” | 可能是板的另一条边，或把折边的厚度线当凸缘 | 用倒角/孔/导轨三条特征交叉确认 |
| 绕竖直杆 ±90° | 图上差别很细（凸缘从左上到右下），极易转反 | 两个候选都渲染，给用户选（见下） |
| 链是镜像 | 以为零件不对/要新建零件 | 弯板有 X=0 对称面、直杆双扁对称，**同一对零件**就能装出镜像链，只需重定各板位姿 |
| “配合全过、干涉 0” | 只是零件不打架；装法可能整体镜像/转错 | 加“同视角对照 + 6 个 Transform2 回读”才算验收 |

## 6. 有歧义时：先 A/B 确认，再动交付物

- 位姿只剩 1–2 个候选时，先出 **A/B 两张同视角渲染**（或俯视图小示意）让用户确认，
  再改模型和全部交付物。
- 真实教训（2026-10-30，图3-11 连接件）：末块弯板绕竖直杆的 90° 方向，
  第一次改到了 −Z 侧（看着“像”图），用户指出“转反了，应该另一个方向”，
  改到 +Z 侧才正确。**±90° 的两个方向在图上差别很小，不要只凭一次目视下结论。**
- 用户说“不一样/装反了”时：先按上面的量化流程核对，**不要先解释成视角问题**；
  用户的肉眼在“朝向、左右、正反”上通常比局部截图可靠。

## 7. 改完的复验与交付物联动

复验（必须有目标级证据）：

1. **重新打开**装配体（独立进程或重开会话）；
2. 回读 6 个 `IComponent2.Transform2`，与设计位姿表逐位对比；
3. `collect_mate_feature_summary` 数配合（排除 MateGroup）；
4. 干涉检查 = 0；
5. 包围盒；
6. 同视角渲染与图并排/叠加。

交付物联动（一个位姿改了，下面都要跟）：

- `001.SLDASM`；
- `预览/`（原图 + `_clean` 白底版）；
- A3 装配图：**等轴测图 + 技术要求里的包围盒 + 序号气泡**（气泡坐标绑在图上，必须重对）；
- 报告 HTML 的正文/表格/附录（包围盒、配合表等多处），再重打印 PDF；
- 提交 zip；
- 交接文档（位姿表、关节表、教训）。
